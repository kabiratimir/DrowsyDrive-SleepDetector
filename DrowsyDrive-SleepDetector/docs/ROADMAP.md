# Development Roadmap

## Phase 1 — Environment
Install Python, virtual environment, dependencies and camera.

## Phase 2 — Camera
Open and test webcam.

## Phase 3 — Face
Detect one face using facial landmarks.

## Phase 4 — Eyes
Extract left/right eye landmarks.

## Phase 5 — EAR
Calculate Eye Aspect Ratio.

## Phase 6 — Blink
Separate short closure from prolonged closure.

## Phase 7 — Drowsiness
Use consecutive frames/time thresholds and smoothing.

## Phase 8 — Sleep
Start and end sleep episodes.

## Phase 9 — Alarm
Play/stop alarm safely.

## Phase 10 — Session
Track study duration and sleep statistics.

## Phase 11 — Database
Store sessions and sleep events in SQLite.

## Phase 12 — GUI
Build a clean student-facing interface.

## Phase 13 — Reports
Show/export session summaries.

## Phase 14 — Advanced detection
Optional head pose, yawning and multi-signal drowsiness score.

## Phase 15 — Documentation
PPT, diagrams, testing, limitations, future scope and viva.
